# MEGABUZZ.WMF — MP3-плеер для Wild Commander

[English](README.en.md) | Русский

Плагин для Wild Commander (WC) на TSConf (ZX Evolution, Karabas Mini и др.), который играет MP3 через декодер Karabas-MegaBuzz: чип VS1053 или программный декодер на neorv32. Работает через регистры `#F4`, `#F5`, `#F6`, `#FB`, `#FC` (см. [PORTS.md](../../../PORTS.md)).

```
+----------------- Megabuzz MP3 Player v0.3.1 -----------------+
| File:   01-kino-gruppa_krovi.mp3                             |
|--------------------------------------------------------------|
| Title:  Группа крови                                         |
| Artist: Кино                                                 |
| Album:  Группа крови                                         |
| Year:   1988      Track: 1/11       Genre: Rock              |
|--------------------------------------------------------------|
| MPEG-1 Layer III  128 kbps CBR  44.1 kHz  Joint Stereo       |
| Decoder: VS1053   Vol: █████████░ -4dB    Bass: 0  Treble: 0 |
|--------------------------------------------------------------|
| ► 01:23 ██████████████████░░░░░░░░░░░░░░░░░░░░░░░░░░░░ 04:47 |
|                                                              |
|                                                              |
| Buf ███████░ 87%                                             |
|--------------------------------------------------------------|
|Spc:next P:prev <>:seek S:pause +-:vol B/T:bass/treb Esc:exit |
+--------------------------------------------------------------+
```

## Установка

1. Положите `MEGABUZZ.WMF` в каталог `WC` на загрузочном устройстве.
2. Добавьте его в секцию `[PLUGINS]` файла `WC/wc.ini` **перед** `GSPLAYER.WMF` (он тоже открывает MP3):

   ```ini
   [PLUGINS]
   MEGABUZZ.WMF
   GSPLAYER.WMF -midi_chip=2
   ```

   WC отдаёт файл первому плагину из списка, у которого есть это расширение. Если Megabuzz или её MP3-декодер не найдены, плагин показывает окно с ответом платы (регистр `#F4`, при сбое ещё и прочитанный на 3,5 МГц) и причиной, а после клавиши WC открывает меню Shift+Enter. Другим плагинам с расширением MP3 WC файл не передаёт: GS Player (Sound Player) в меню Shift+Enter не попадает, так что, пока `MEGABUZZ.WMF` стоит в списке раньше, MP3 через GS не сыграть. Те же сведения о плате показывает пункт плагина в меню F10. В меню Shift+Enter плагин называется «Play on Megabuzz».
3. Выключите Z-Controller и DivMMC Megabuzz (в конфигураторе на A2/A3, DIP-переключателями на A1): у TSConf свой Z-Controller на тех же портах, и они будут мешать SD-карте хоста.

Нужны прошивка Megabuzz с MP3-декодером (Rev.A3 или любая ревизия на XC6SLX25) и регистром идентификатора `#F4`, а также WC 1.09 или новее (плагинная система `#10`).

`MEGABUZZ_EMU.WMF` — та же сборка без Megabuzz: порты не трогает, FIFO программный и убывает в темпе потока, в заголовке окна написано `EMU`. Звука нет, она нужна, чтобы посмотреть интерфейс, теги, время и клавиши на любом хосте с TSConf. В `wc.ini` её ставят вместо `MEGABUZZ.WMF`.

## Управление

| Клавиша | Действие |
|---|---|
| `Space`, `Enter` | следующий трек |
| `P`, `Backspace` | предыдущий трек |
| `←` / `→` | перемотка на 10 с назад / вперёд |
| `S` | пауза |
| `+` / `-`, `↑` / `↓` | громкость, шаг 2 дБ |
| `B` / `T` | бас / верха по кругу 0..7 (только чип VS1053) |
| `Esc` | выход в WC |

Когда трек доиграл, плагин переходит к следующему файлу в панели, на последнем файле — возвращается в WC. Громкость и эффекты хранятся в регистрах Megabuzz и переходят от трека к треку.

## Что показывается

- **Имя файла** — длинное имя из WC.
- **Теги ID3v2.2, 2.3, 2.4:** название, исполнитель (или исполнитель альбома), альбом, год, номер трека, жанр (числовые жанры ID3v1 переводятся в названия). Кодировки UTF-16, UTF-8 и однобайтовая, которая считается CP1251. Кириллица выводится в CP866. Символы вне кириллицы и ASCII заменяются на `?`. Обложки и другие большие кадры пропускаются без чтения.
- **Поток:** версия MPEG, слой, битрейт (для VBR — средний), частота, режим каналов.
- **Время и прогресс.** Длительность VBR берётся из заголовка Xing/Info или VBRI, для CBR считается по битрейту. Прошедшее время считается по позиции в файле минус заполнение FIFO, поэтому оно верно и после перемотки.
- **Buf** — заполнение FIFO декодера (4 КБ).

## Ограничения

- ID3v1 (в конце файла) не читается: до начала проигрывания дочитать до конца файла WC не даёт.
- Минуты на экране ограничены 99:59, перемотка работает для файлов до 32 МБ.
- Пока только MP3. Чип VS1053 умеет ещё AAC, WAV, OGG и другие форматы, их можно добавить позже.
- Плагин ищет плату на 14 МГц, если ответа нет — на 7 и 3,5 МГц, и играет на той частоте, где плата ответила: TSConf замедляет обращения к слоту только для AY и ВГ93, а остальные порты (и `#FC3B`/`#FD3B`) читаются на полной частоте. На 7 и 3,5 МГц для 320 кбит/с нужна SD-карта, которая через WC читается не медленнее ~80 КБ/с (на 14 МГц хватает ~58 КБ/с). Ответ платы на каждой частоте показывает пункт плагина в F10.
- Пиков L/R пока нет (место под них оставлено в окне), см. пункт 6 в [BACKLOG.md](../../../BACKLOG.md).

## Сборка и тесты

Нужен [sjasmplus](https://github.com/z00m128/sjasmplus):

```
make            # -> MEGABUZZ.WMF и MEGABUZZ_EMU.WMF
```

Если на какой-то версии WC функция `LOADNONE` (`#3D`) не работает, соберите `sjasmplus --inc=src -DNO_LOADNONE src/main.asm`: тогда перемотка и пропуск обложек идут через обычное чтение, медленнее.

`make test` прогоняет плагин в симуляторе (`test/wcsim.py`): ядро Z80 из пакета [z80](https://github.com/kosarev/z80), эмуляция WC API (окна, `LOAD512`, `GIPAGPL`, `LOADNONE`, клавиши, таймер) и портов Megabuzz с FIFO 4 КБ, который опустошается в темпе битрейта. Тесты проверяют теги и кодировки, поток, который ушёл в декодер, клавиши, перемотку, коды выхода и запас FIFO при медленной SD-карте. Нужны `ffmpeg` и Python с пакетами `z80` и `mutagen`:

```
python3 -m venv venv && venv/bin/pip install z80 mutagen
make test PYTHON=venv/bin/python
```

Симулятор не заменяет проверку на железе: цвета, глифы шрифта WC (`►`, `■`, `║`, `█`) и тайминги шины проверяются только на реальном хосте.
