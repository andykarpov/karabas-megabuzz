# Порты Megabuzz 

Все звуковые устройства на стороне Megabuzz доступны через свои порты. Также имеются служебные порты для управления самим Megabuzz (для ревизий A2, A3). В данной документации будут описаны только специфические порты - для vs1053, для управления флагами настроек.

## Порты ZXUNO

Для управления чипом vs1053 и служебные порты доступны через набор регистров портов ZXUNO #FC3B / #FD3B.

### Порт выбора регистра ZXUNO - #FC3B

Данный порт используется по стандарту ZXUNO для выбора регистра, с которым работает порт данных #FD3B.

На данный момент плата Megabuzz поддерживает такие кастомные регистры портов ZXUNO:

    - #F5 - регистр статуса и управления FIFO VS1053
    - #F6 - регистр данных FIFO VS1053
    - #F7 - регистр байта конфигурации Megabuzz
    - #F8 - регистр ПЗУ Megabuzz
    - #F9 - регистр управления Megabuzz
    - #FA - регистр адреса байта конфигурации Megabuzz
    - #FB - регистр громкости VS1053
    - #FC - регистр эффектов VS1053

##### Регистр #F5 - статус и управление FIFO VS1053

при чтении из порта данных, возвращается:

    - бит 7 - статус переполнения FIFO VS1053
    - бит 6:0 - количество занятых блоков по 32 байта в FIFO VS1053

при записи в порт данных

    - бит 7 - сбрасывает FIFO и VS1053 через soft reset
    - биты 6:0 - n/a

##### Регистр #F6 - данные FIFO VS1053

    - при записи - записывается переданный байт данных в FIFO VS1053
    - при чтении - отдается то же самое, что и для регистра #F5 (то есть статус FIFO)

##### Регистр #F7 - регистр байта конфигурации Megabuzz

    - при записи в порт данных - пишется байт конфигурации по адресу, выставленному для регистра #FA
    - при чтении из порта данных - отдается байт конфигурации по адресу, выстанвленному для регистра #FA

В данных момент существует только 2 байта конфигурации

Первый байт конфигурации (адрес = 0x00):

    - бит 0 - DivMMC вкл = 1, выкл = 0
    - бит 1 - Z-Controller вкл = 1, выкл = 0
    - бит 2 - Soundrive
    - бит 3 - Beeper
    - бит 4 - SAA1099
    - бит 5 - General Sound
    - бит 6 - Turbosound FM + MIDI
    - бит 7 - OPL3

Второй байт конфигурации (адрес = 0x01)

    - бит 0 - Включен ли столбик VU-метра
    - бит 1 - Включена ли точка VU-метра
    - бит 2 - Переключает направление VU-метра в обратную сторону

##### Регистр #F8 - регистр ПЗУ Megabuzz

    - бит 0 - переключает между штатной ПЗУ хоста или ПЗУ конфигуратора Megabuzz. 1 = ПЗУ Megabuzz, 0 - ПЗУ спектрума

##### Регистр #F9 - регистр управления Megabuzz

    - бит 0 - значение 1 - осуществляет сброс хоста

##### Регистр #FA - адрес байта конфигурации Megabuzz

    - биты 7:0 - задают адрес байта конфигурации. Валидные значения на сегодня - 0x00, 0x01

##### Регистр #FB - громкость VS1053

    - значение 0x00 - максимальная громкость
    - значение 0xFE - минимальная громкость

По-умолчанию, плата сбрасывается со значением громкости 0x08

##### Регистр #FС - управление эффектами VS1053

    - биты 7:6 - ear speaker (00 - off, 01 - low, 10 - mid, 11 - high)
    - биты 5:3 - treble boost (000 - off, 111 - max +10.5dB) at 5kHz
    - биты 2:0 - bass boost (000 - off, 111 - max + 14dB) at 60Hz

По-умолчанию, регистр эффектов содержит значение 0x00

### Порт данных ZXUNO - #FD3B

В данный порт пишется значение в регистр, выбранный перед этим через порт #FC3B.
Значения регистров доступны и для чтения через этот порт.
